This browser extension starter kit helps students plan assignments, find papers, read difficult material, and finish focused study sessions for free. If you searched for an extension for students, start with the job slowing you down: capturing deadlines, collecting sources, or keeping distractions away.

The list follows a study week, from checking assignments to saving Friday’s research. Install two or three tools first; each earns its place by doing a different job. These picks focus on desktop browsers, and browser support varies. ## Set it up in 10 minutes

1. **Minutes 0–2:** Pick your biggest obstacle. Install Todoist for forgotten tasks, Zotero Connector for lost sources, or LeechBlock NG for distractions.
2. **Minutes 2–5:** Configure one real example: capture an assignment, save a paper, or schedule a study block. Zotero’s desktop setup may need extra time.
3. **Minutes 5–8:** Add one supporting tool. Pair Scholar Button with Unpaywall for research, or Read Aloud with a reading assignment.
4. **Minutes 8–10:** Pin the extensions you will use regularly. Try the complete workflow on an actual course page and check the result.

## Quick answers

**Which extension should a student install first?**

Choose by the immediate problem. Todoist suits assignment capture, Zotero Connector suits source collection, and LeechBlock NG suits focused work. You do not need the whole list.

**Are these free trials?**

The recommended core jobs are available without a trial timer. Some tools offer optional upgrades or limit storage, projects, or voice usage; each catch is listed above.

**Will they work on a school Chromebook?**

Chrome-compatible extensions may work, but your school’s administrator can restrict installations. Use the official installation links and follow your school’s device rules.

**Can extensions finish assignments for me?**

These tools help you manage work, access sources, and read material. You still need to evaluate evidence, check citations, and follow your course’s rules.
