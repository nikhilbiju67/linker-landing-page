## How to choose between them

Choose one main course and one place to practice. For a broad start, use freeCodeCamp. For websites, follow The Odin Project and keep MDN nearby. Choose CS50x if understanding algorithms and computer memory matters as much as making something visible.

For data work, start with Kaggle’s introductory programming material, then add SQLBolt. For children or anyone who prefers visual experimentation, begin with Scratch. Save Full Stack open until you can write and debug smaller programs independently.

Give your chosen course a concrete goal: a personal webpage, a small game, or a script that summarizes a file. Finish that before collecting more courses. When your webpage is ready to share, these [free tools for making a website](/blog/how-to-make-a-free-website) cover practical publishing options.

## Quick answers

**What are good sites to learn coding for free?**

freeCodeCamp is the broadest starting point here. The Odin Project suits future web developers, while CS50x suits learners who want deeper computer science foundations. All three provide substantial learning without a trial timer.

**What are good sites to learn Python?**

Start with Kaggle’s Intro to Programming and Python courses if you want browser exercises. Use Exercism for more practice. The official Python tutorial is better suited to people who already understand basic programming.

**What are good sites to learn SQL?**

Start with SQLBolt for short lessons and browser queries. Khan Academy offers a gentler introduction with explanations and practice, while CS50x places SQL within a broader programming course.
