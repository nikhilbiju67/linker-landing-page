These six free tools show you how to save links in a folder, whether you want a simple browser bookmark folder or a collection you can open on your phone and computer. The quickest method: create a folder in your browser’s bookmark manager, bookmark a page, and choose that folder as its location.

<!-- picks -->

## A practical routine for keeping link folders useful

Start with three destinations: **Inbox**, **Active projects**, and **Reference**. Save uncertain links to Inbox, then give each useful bookmark a name that explains its purpose. “Passport renewal checklist” is easier to recognize than a vague page title.

Once a week, empty Inbox and remove links you no longer need. Keep folders broad until a specific project needs its own space. A bookmark stores an address; it does not guarantee that the original page will remain available.

If your main goal is finishing articles rather than collecting references, these [free read-it-later apps](/blog/read-it-later-apps) fit that job better.

### Quick answers

**How to save links in Chrome?**

Click the address-bar star and choose a folder. Create folders first in Bookmark manager if you want a clear destination for each save.

**How to save links on iPhone or in Safari?**

Use Safari’s Add Bookmark command and select a folder. To reorganize an existing bookmark, edit its Location. The Safari item above links to Apple’s layout-specific instructions.

**How to save links to files or on desktop?**

For a plain file, paste URLs into a text document and save it in your chosen desktop folder. For a portable bookmark collection, Chrome’s Bookmark manager offers **Export bookmarks**, which creates an HTML file. That file stores links, not offline copies of the pages. See Google’s [export instructions](https://support.google.com/chrome/answer/96816?hl=en-u).

**How to save links to Google Drive?**

Put a Google Doc containing your URLs inside a Drive folder. You can also upload a text file of links. A Drive shortcut to a Drive file is different from a bookmark to an outside website.
