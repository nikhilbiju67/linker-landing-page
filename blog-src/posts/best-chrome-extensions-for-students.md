The best Chrome extensions for students help you finish actual coursework: capture an assignment, find a readable paper, keep its citation, and submit a cleaner draft. This starter kit suits high school and college students using Chrome on a computer, with free tools arranged around a typical study week.

Every pick has a useful free core without a trial timer. You don’t need all 12; start with the job that keeps slowing you down. For tools you can use directly in a browser, pair this kit with these [useful websites for students](/blog/useful-websites-for-students).

## Set it up in 10 minutes

1. **Minutes 1–2:** Choose one immediate problem: missed tasks, distracting sites, scattered sources, or proofreading. Install the matching extension from its official page.
2. **Minutes 3–5:** Configure one useful action. Add an assignment with a due date, create a study block, or save a research source.
3. **Minutes 6–8:** Try that action on real coursework. Check the saved citation, reopen the offline page, or listen to a paragraph.
4. **Minutes 9–10:** Pin the extension you will use regularly. Add another only when you can name its job. Zotero’s desktop setup may need extra time.

## Quick answers

**Best Chrome extensions for Android**

Chrome on Android phones does not run these desktop extensions. “Add to Desktop” queues an extension for your computer. Use mobile apps where available, such as Todoist or Bitwarden. [Google’s installation guidance](https://support.google.com/chrome/answer/2664769) explains the distinction.

**Best Chrome extensions for YouTube**

Video Speed Controller is the relevant pick here for reviewing tutorials. If YouTube’s built-in playback controls already cover your needs, you can skip the extension.

**Best Chrome extensions for teachers**

Zotero Connector helps collect references for lessons, LanguageTool checks written instructions, and Read Aloud provides a listening option. On school-managed computers, administrators may restrict installation, as [Google’s help page](https://support.google.com/chrome/answer/2664769) explains.

**Best Chrome extensions for work**

Todoist, Bitwarden, and LanguageTool also fit internships and part-time jobs: track tasks, manage logins, and review emails. Follow your workplace’s rules before installing them.
