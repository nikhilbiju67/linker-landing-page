To reduce image size for free, open your picture in Squoosh, lower the quality setting, and download the smaller copy; these tools suit anyone facing an upload limit or sharing oversized photos. If the file is still too big, reduce its pixel dimensions and check that text and faces remain clear.

File size means KB or MB; dimensions mean width and height in pixels. Compression can reduce the first without changing the second. Start with Squoosh for control, or choose a batch tool below when you have a folder of pictures.

## How to reduce image size for free with Squoosh

1. Open [Squoosh](https://squoosh.app/) and select or drop in your original picture. Keep the original as your backup.
2. Choose an output format the destination accepts. JPEG is a practical choice for photos; use a format supporting transparency if you need a transparent background.
3. Lower quality gradually. Compare the preview at normal viewing size, then inspect faces, edges, and small text more closely.
4. If the file remains too large, enable resizing and reduce its width while keeping its proportions. Follow any minimum dimensions required by the upload form.
5. Download the result and check its actual file size. Leave a little room below the upload limit, then open the saved file to confirm it looks acceptable.

### Quick answers

**How to compress image size?**

Lower the image’s compression quality, reduce unnecessary pixel dimensions, or use a more efficient format accepted by the destination. Begin with the original each time. Changing a filename from `.png` to `.jpg` does not convert or compress the image.

**Can I reduce image size without losing quality?**

Sometimes. Lossless optimization removes redundant data without changing pixels, but savings depend on the original. Large reductions often require fewer pixels, fewer colors, or lossy compression. A picture can look very similar while still losing data; none of these tools can guarantee a dramatic reduction for every file.

**Is there a free online tool to reduce PDF file size?**

Yes, but use a PDF compressor when the file itself is a PDF. Converting document pages to JPG can discard searchable text and document features. See these [free tools to compress PDF file size](/blog/how-to-compress-pdf-file-size) for options and their catches.
