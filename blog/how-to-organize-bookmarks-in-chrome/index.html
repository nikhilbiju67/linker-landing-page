How to organize bookmarks in Chrome with 7 free tools

By the Linkker team · 19 November 2026 · 5 min read

To organize bookmarks in Chrome, open Bookmark Manager, create a few folders, and drag your saved pages into them. That’s enough for most people who want to find yesterday’s link without scrolling through years of saves. Google’s Chrome bookmark guide

Start with the links you use every week. Once those are easy to reach, pick a tool for whatever still slows you down, such as duplicate bookmarks, a backlog of articles, or links that keep getting stranded on your phone.

Quick picks

  1. Chrome Bookmark Manager: Sorting the bookmarks you already have in Chrome
  2. Markd — Bookmark Manager & Cleaner: A one-time cleanup of a crowded Chrome library
  3. Raindrop.io: Research and projects that need folders and tags
  4. Start.me: Keeping daily shortcuts visible on one page
  5. Instapaper: Separating this week’s reading from reference links
  6. PairDrop: Sending one URL to a nearby device without installing an app
  7. LocalSend: Regular link and file transfers between nearby devices
  1. 1

    Chrome Bookmark Manager

    support.google.com
    Free

    Create folders, move saved pages, and tidy your bookmarks bar with Chrome’s built-in controls.

    On desktop, open Chrome’s three-dot menu and choose Bookmarks and lists → Bookmark Manager. Select where the folder should go, then open the manager’s three-dot menu and choose Add new folder. Drag saved links into the folder in the left sidebar. To find a link later, type @bookmarks in the address bar, press Tab, and enter a keyword. Give bookmarks names you’ll remember, such as “Submit expenses” for a page titled “Employee Portal.” Chrome bookmark controls

    Best for
    Sorting the bookmarks you already have in Chrome
    The catch
    You choose where bookmarks go. Access on other devices requires signing in to Chrome.
    Visit support.google.com ↗
  2. 2

    Markd — Bookmark Manager & Cleaner

    chromewebstore.google.com
    Free plan

    Scan your existing Chrome bookmarks for duplicates, broken links, and empty folders.

    Use Markd for a cleanup before you start moving folders around. Its free scan flags duplicate links, missing pages, and empty folders in your existing Chrome library. Export an HTML backup first, then check which copy of a duplicate you want to keep. The same page might belong in two project folders. The extension also lets you filter by folder and sort by domain, which helps when several old links came from the same site. Markd’s Chrome Web Store listing

    Best for
    A one-time cleanup of a crowded Chrome library
    The catch
    Tags and bulk moves require an upgrade. Undo for cleanup fixes lasts 10 minutes.
    Visit chromewebstore.google.com ↗
  3. 3

    Raindrop.io

    raindrop.io
    Free plan

    Organize bookmarks into collections and tags you can use across devices.

    Raindrop.io is useful when a link belongs in more than one place. Save a hotel to a Chicago trip collection and tag it book soon, then use that same tag for links in other trip collections. You can import a Chrome bookmark export and keep unlimited bookmarks and collections on the free plan. Start with a few tags you’ll actually search for so you have less to remember when filing a link. Raindrop.io import guide · Free and Pro features

    Best for
    Research and projects that need folders and tags
    The catch
    Searching inside saved pages and keeping permanent copies require an upgrade.
    Visit raindrop.io ↗
  4. 4

    Start.me

    start.me
    Free with ads

    Put groups of frequently used bookmarks on a visual start page.

    Build a page with columns for the places you open throughout the day. A work page might have one group for time sheets and expenses, another for project dashboards, and a third for reference docs. Start.me lets you import browser bookmarks and rearrange groups on the page. You can open the dashboard as a regular website, or use the optional extension to make it your new tab page. Start.me setup guide

    Best for
    Keeping daily shortcuts visible on one page
    The catch
    The free version shows ads and caps you at three start pages.
    Visit start.me ↗
  5. 5 I

    Instapaper

    instapaper.com
    Free plan

    Save articles from Chrome to a reading queue you can open on your phone.

    Send articles you mean to read into Instapaper so they leave room on the bookmarks bar for pages you reopen often. The free account saves articles, organizes them into folders, and syncs your queue between the web app and iPhone or Android. Try a single Read next folder. When an article turns out to be something you’ll consult regularly, give it a permanent home in your bookmark library. Instapaper feature comparison

    Best for
    Separating this week’s reading from reference links
    The catch
    Full-text search and a permanent archive of saved articles require an upgrade.
    Visit instapaper.com ↗
  6. 6 P

    PairDrop

    pairdrop.net
    Free & open source

    Send a copied link between your phone and computer from the browser.

    Open PairDrop in a browser on both devices while they’re on the same Wi-Fi. Once the other device appears, use its text-send option and paste the URL. This works well for a one-off handoff, such as opening a restaurant link on a laptop to make a reservation. You can send the link without creating an account. Save it in Chrome after it arrives if you’ll need it again. PairDrop project guide

    Best for
    Sending one URL to a nearby device without installing an app
    The catch
    Both devices need the site open for the handoff. You save the link separately.
    Visit pairdrop.net ↗
  7. 7

    LocalSend

    localsend.org
    Free & open source

    Send links and files between devices on your local network.

    Install LocalSend on the devices you use together. On the sender, choose Text, paste a URL, and select the receiving device. The same app can send a Chrome bookmark backup as a file, so it fits if you regularly move both links and documents between your phone and computer. It works over your local network without an account, including when that network has no internet connection. LocalSend setup guide

    Best for
    Regular link and file transfers between nearby devices
    The catch
    For app-to-app transfers, both devices need the app and must be on the same local network.
    Visit localsend.org ↗

A ten-minute bookmark routine

  1. Back up what you have. In Chrome Bookmark Manager, open the three-dot menu and select Export bookmarks. Keep the HTML file before you delete duplicates or rearrange a large collection. Chrome’s export instructions
  2. Put frequent links within reach. Keep the pages you open every week on the bookmarks bar. Give the rest a few folders named for things you do, such as Pay bills, Plan trips, or Work reference. If you share links outside Chrome, see these ways to save links in a folder.
  3. Clear a small batch once a week. Rename vague titles, delete links you’re done with, and file the ones you’ll use again. If most of the pile is unread articles, give them a queue in a read-it-later app.

Quick answers

How do I organize bookmarks into folders in Chrome?

Open Bookmarks and lists → Bookmark Manager from Chrome’s three-dot menu. Create a folder from the manager’s three-dot menu, then drag existing bookmarks onto it in the sidebar. To file a new bookmark, click the star in the address bar and choose the folder when you save it. Google’s folder instructions

How do I organize the bookmarks bar in Chrome?

Go to Bookmarks and lists → Show bookmarks bar. Drag bookmarks left or right to reorder them. Right-click the bar and choose Add folder to group related links. Shorten long bookmark names so more of them fit. Google’s bookmarks bar instructions

How do I organize bookmarks on a Mac?

In Chrome, press Command + Option + B to open Bookmark Manager. Command + Shift + B shows or hides the bookmarks bar. In Safari, open Bookmarks in the sidebar. Use its More menu to create a folder or choose a sort order. To drag items into your own order, turn off Show Folders on Top first. Chrome keyboard shortcuts · Apple’s Safari bookmark guide

How do I organize bookmarks in Edge?

Edge calls them Favorites. Open Settings and more → Favorites, then choose More options → Open favorites page. From there you can create folders and move links, or right-click and choose Sort by name for alphabetical order. Microsoft’s Favorites guide
